How It Works

This analyzer uses a RandomForest Machine Learning model trained to detect suspicious and phishing URLs.

It analyzes 21 different features of each URL including:

  • URL length and structure
  • HTTPS encryption presence
  • IP address detection
  • Suspicious keywords (login, verify, update, etc.)
  • Special character patterns
  • Domain and subdomain analysis
  • And many more indicators…
